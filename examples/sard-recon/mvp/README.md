# ترجمان: النموذج الأولي

صفحة ويب واحدة تنفذ الحلقة الأساسية لفكرة SARD على الكمبيوتر: صورة اللعبة ← قراءة السطر الإنجليزي ← ترجمة ← عربي فوق مكانه.

## التشغيل

```bash
cd examples/sard-recon/mvp && python3 -m http.server 8765
```
ثم افتح `http://localhost:8765` في Chrome أو Edge (الكاميرا ومشاركة الشاشة تحتاج localhost أو https).

1. ضع مفتاح Gemini (مجاني من aistudio.google.com). بدونه يستخدم مترجمًا مجانيًا أبطأ وأضعف.
2. اختر المصدر:
   - **كرت التقاط**: البلايستيشن ← HDMI ← Capture card (USB) ← الكمبيوتر. أفضل جودة وبدون تأخير.
   - **مشاركة نافذة**: نافذة PS Remote Play أو chiaki-ng أو تطبيق Xbox على الكمبيوتر.
   - **عرض تجريبي**: مشهد مدمج للتجربة بدون جهاز.
3. في GTA: فعّل Subtitles بالإنجليزي. اسحب المربع الأصفر فوق مكان الترجمة (أسفل الوسط) وكبّره من الزاوية.
4. "ابدأ الترجمة". ثم "ملء الشاشة" ووصّل الكمبيوتر بالتلفزيون.

## ما تم قياسه (العرض التجريبي، Chromium)

| المقياس | النتيجة |
| --- | --- |
| OCR للسطر | 100 إلى 140ms |
| ترجمة سطر جديد (gemini-3.5-flash-lite) | 0.6 إلى 1 ثانية |
| من ظهور السطر إلى العربي، سطر جديد | 0.9 إلى 1.4 ثانية |
| سطر مكرر من ذاكرة الترجمة | حوالي 0.27 ثانية |

الـ OCR (Tesseract.js) يقرأ الحروف صحيحة لكن يلصق بعض الكلمات أحيانًا. الترجمة تصلح هذا لأن النموذج يستنتج
الجملة المقصودة. الترقية التالية: PaddleOCR PP-OCRv5 عبر onnxruntime-web، وهو ما يستخدمه SARD.

## المزايا

- فلتر "حرف أبيض بحد أسود": يتجاهل السماء والطرق الفاتحة ويقرأ الترجمة فقط.
- لا يقرأ إلا عندما يتغير السطر ويستقر، ويخفي العربي عندما يختفي الإنجليزي.
- ذاكرة ترجمة مع مطابقة تقريبية (90٪): السطر المكرر يظهر فورًا حتى لو اختلفت قراءته قليلًا.
- قاموس GTA (فرانكلين، مايكل، تريفر، لوس سانتوس...) قابل للتعديل، واللهجة: سعودي أو فصحى أو خليجي، وتلطيف الشتائم.
- "صحّح الترجمة" لأي سطر: يُحفظ كمراجَع ويُستخدم دائمًا. تصدير واستيراد الذاكرة JSON.
- تخصيص الخط (Cairo, Tajawal, IBM Plex Sans Arabic, Noto Naskh) والحجم والألوان، وملخص الجلسة بالعربي.
