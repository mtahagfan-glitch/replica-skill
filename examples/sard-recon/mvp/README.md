# هنو

صفحة ويب شخصية تترجم ترجمة الألعاب الإنجليزية إلى عربي وتعرضها فوق مكانها. ملف واحد: `index.html`.
لا تحتاج سيرفر ولا تثبيت: افتح الملف في Chrome أو Edge.

## طريقة التوصيل

**الطريقة 1: كرت التقاط (الأفضل)**
```
PS5 ──HDMI──► كرت التقاط ──USB──► الكمبيوتر ──HDMI──► التلفزيون
```
التلفزيون يعرض صفحة هنو بملء الشاشة: اللعبة والعربي فوقها. يد التحكم متصلة بالبلايستيشن كالمعتاد.

**الطريقة 2: بدون كرت (مجاني)**
تطبيق PS Remote Play الرسمي على الكمبيوتر ← "مشاركة نافذة" في هنو.

## ما تم قياسه (Chromium، العرض التجريبي، فتح الملف مباشرة)

| المقياس | PaddleOCR | Tesseract |
| --- | --- | --- |
| دقة القراءة | الجمل كاملة صحيحة بالمسافات والفواصل | الحروف صحيحة، بعض الكلمات ملتصقة |
| زمن القراءة | حوالي 0.29 ثانية | حوالي 0.15 ثانية |
| من ظهور السطر إلى العربي | حوالي 1.3 ثانية | حوالي 1.3 ثانية |
| سطر مكرر من الذاكرة | حوالي 0.3 ثانية | حوالي 0.3 ثانية |

أول تشغيل لـ PaddleOCR ينزّل نموذجًا حجمه 8MB مرة واحدة.

## المزايا

- قراءة PaddleOCR PP-OCRv5 داخل المتصفح، مع Tesseract احتياطي.
- فلتر "حرف أبيض بحد أسود" يحدد مكان الترجمة ويتجاهل الخلفية.
- صوت اللعبة من كرت الالتقاط يُشغَّل في الصفحة.
- ذاكرة ترجمة مع مطابقة تقريبية، وتصحيح يدوي يُحفظ.
- قاموس GTA، لهجة سعودي أو خليجي أو فصحى، تلطيف الشتائم.
- خطوط Cairo و Tajawal و IBM Plex Sans Arabic و Noto Naskh، وملخص الجلسة.
- كل الإعدادات والمفتاح والذاكرة محفوظة في متصفحك فقط.

## اختصار الضغطة الواحدة على الماك

نزّل `hanu.html` و `install-hanu-mac.sh` في مجلد التنزيلات، ثم في Terminal:
```bash
bash ~/Downloads/install-hanu-mac.sh
```
يظهر تطبيق **هنو** على سطح المكتب. الضغط عليه يفتح PS Remote Play، ثم يفتح هنو في نافذة Chrome خاصة بملء الشاشة،
ويختار نافذة Remote Play تلقائيًا ويبدأ الترجمة (`hanu.html?auto=1`). إذا لم يجد النافذة، يظهر زر واحد "ابدأ اللعب بالعربي".
