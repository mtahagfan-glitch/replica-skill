# هنو الشامل (قيد البناء)

تطبيق Android TV واحد يسوي كل شيء بدون ماك ولا جوال: يتصل بالبلايستيشن عبر Remote Play، يقرأ الترجمة الإنجليزية،
يترجمها، ويرسم العربي فوق اللعبة.

مبني فوق [chiaki-ng](https://github.com/streetpea/chiaki-ng) (عميل Remote Play مفتوح المصدر، AGPL-3.0، يدعم Android TV).
استخدام شخصي، غير منشور.

## الحالة

| الجزء | الحالة |
| --- | --- |
| اختيار الأساس (chiaki-ng، فيه تطبيق Android TV جاهز) | تم |
| `HanuConfig.kt`: الإعدادات على التلفزيون (المفتاح، اللهجة، القاموس، منطقة الترجمة) | مكتوب، لم يُبنَ |
| `PsnAccount.kt`: Account ID من رابط تسجيل دخول PSN في متصفح الجوال | مكتوب، لم يُبنَ |
| `Translator.kt`: Gemini + ذاكرة ترجمة + مطابقة تقريبية | مكتوب، لم يُبنَ |
| قارئ الترجمة (ML Kit) من صورة البث | لم يبدأ |
| صفحة الإعدادات من الجوال (يقدمها التلفزيون على المنفذ 8787) | لم تبدأ |
| ربطها بشاشة البث في chiaki-ng | لم يبدأ |
| بناء APK | متوقف: أداة الصلاحيات في الجلسة رفضت أمر البناء |

الملفات في `java/com/metallic/chiaki/hanu/` تُنسخ إلى `android/app/src/main/java/com/metallic/chiaki/hanu/` في chiaki-ng.
