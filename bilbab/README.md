# بالباب

ولي الأمر يضغط **«وصلت»** عند بوابة المدرسة، فتظهر أسماء أبنائه فوراً عند مشرف البوابة ومعلمة الفصل وعلى شاشة الساحة، وتنطقها بصوت. وعند التسليم يصله إشعار.

اسم عمل مؤقت. افحص العلامة التجارية (SAIP) والنطاق قبل اعتماده.

## التشغيل

```bash
npm start          # Node 22.5+، بدون npm install
# http://localhost:3000
```

بيانات تجريبية تُنشأ تلقائياً:

| الواجهة | الرابط | الدخول |
| --- | --- | --- |
| ولي الأمر / السائق | /parent/ | 0500000001 (الأب)، 0500000002 (الأم)... الرمز يظهر على الشاشة في وضع التطوير |
| البوابة | /gate/ | `gate` / `demo1234` |
| المعلمة | /teacher/ | `teacher3a` / `demo1234` |
| الإدارة | /admin/ | `admin` / `demo1234` |
| شاشة الساحة | الرابط يُطبع عند التشغيل، وموجود في الإدارة | بدون دخول |

للتجربة من الكمبيوتر: فعّل «وضع التجربة: اعتبرني عند المدرسة» في شاشة ولي الأمر (يظهر في وضع التطوير فقط).

## الاختبارات

```bash
npm test       # 18 اختبار API: الدخول، النطاق، الوقت، التفويض، الصلاحيات، الاستيراد، الحماية
npm run e2e    # Playwright: أب على iPhone + بوابة + معلمة + شاشة، المسار كاملاً
```

## الإنتاج

انسخ `.env.example` إلى `.env`، واضبط `NODE_ENV=production` و`SEED=0` ومزوّد الرسائل، وضعه خلف HTTPS (Caddy أو Nginx) مع `TRUST_PROXY=1`. الموقع الجغرافي في المتصفح يتطلب HTTPS.
