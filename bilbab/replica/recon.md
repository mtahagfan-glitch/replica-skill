## كيف يعمل الأصل (الحلقة الأساسية)

1. المدرسة ترسم سياجاً جغرافياً (~200 ياردة) وتحدد وقت الانصراف.
2. ولي الأمر يفتح التطبيق في طابور السيارات ويضغط Announce (يتطلب الموقع "دائماً").
3. الموظفون يرون الإعلان، الطالب يُستدعى، ويُسلَّم. ولي الأمر يستلم إشعار "تم الانصراف".
4. التفويض: ولي الأمر يضيف شخصاً آخر للاستلام، مع مواعيد نهائية يومية للتغييرات.
5. بديل بدون جوال: بطاقة رقم السيارة المطبوعة.

السعر المعلن: من 99$ شهرياً أو 750 إلى 4000$ سنوياً للمدرسة.

## المسارات

- **F01 ولي الأمر يستلم**: S03 (يقترب ← يتفعّل الزر) ← ضغطة ← S06/S07/S08 تظهر فوراً ← المعلمة «أرسلته» ← البوابة «تم التسليم» ← إشعار لولي الأمر. **ضغطة واحدة** (والوضع التلقائي: صفر ضغطات).
- **F02 تفويض السائق**: S04 نموذج واحد (اسم، جوال، صلة، الأبناء، المدة) ← السائق يدخل برقمه ويرى أبناءك فقط ← الأب يُبلَّغ بكل خطوة.
- **F03 بدون جوال/إنترنت**: ولي الأمر يقرأ رمزه (6 أرقام) ← المشرف يُدخله في S06.
- **F04 المعلمة**: S07 ← «أرسلته للبوابة».
- **F05 الإدارة**: S09 ← استيراد CSV من نور ← ضبط النطاق ← رابط الشاشة.

## نموذج البيانات

`schools, gates, students, guardians, guardian_students (owner|delegate + أيام + تواريخ), staff, sessions, otps, pickups (announced→sent→released|cancelled), audit` (انظر `schema.sql`).

## خارج النطاق

- تكامل رسمي مع نور / مدرستي: لا يوجد API عام؛ الاستيراد عبر CSV.
- دخول نفاذ: يتطلب اعتماداً حكومياً؛ مرحلة لاحقة.
- CarPlay وإشعارات والتطبيق مغلق: تحتاج تطبيقاً أصلياً (Expo).
